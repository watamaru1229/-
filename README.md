# 第2号 (仮) - 3Dハクスラシューティングゲーム

Unityで制作した、3Dハクスラシューティングゲームです。
ゲームの「手触り（気持ちよさ）」と「プログラムの堅牢性・最適化」にこだわって制作しました。

## 開発環境
- Unity 使用したバージョン。例：6000.4.3f1
- 言語: C#

## 技術的な工夫とこだわり

### 1. キューを用いた計算量 O(1) の動的オブジェクトプール
大量の弾やエフェクトが頻繁に生成・破棄されることによる処理落ち（GCスパイク）を防ぐため、独自のオブジェクトプールを実装しました。
- **工夫点**: 弾データ（BulletData）ごとに専用の空きキュー（`Queue`）をDictionaryで動的に生成・管理する設計にしました。これにより、オブジェクトの取得・返却を常に計算量 O(1) の高速処理で行うことができます。
- **堅牢性**: プールから取得する際、予期せぬオブジェクトの破壊（Null）を検知してスキップするセーフティループを実装し、ゲームが絶対にクラッシュしない設計にしました。

### 2. 企画職の調整効率を意識した「マスターとインスタンス」の分離設計
ハクスラ要素（武器のランダムステータス生成）を実装するにあたり、設計の綺麗さとチーム開発での作業効率を意識しました。
- **工夫点**: 不変の基本情報を管理するマスターデータ（`WeaponData`：ScriptableObject）と、ゲーム実行時に動的に生成される個別の状態を保持する実体（`WeaponInstance`：通常のC#クラス）に分離しました。
- **チームへの配慮**: `WeaponInstance` を `[System.Serializable]` にすることで、プランナーやデザイナーがインスペクター上で直接パラメータの変化やランダム生成の挙動を確認・調整しやすいワークフローを実現しました。
